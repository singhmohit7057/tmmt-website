TMMT is a high-fidelity digital agency platform engineered for **sub-400ms latency** and **Retina-ready visual precision**. This repository houses the unified frontend architecture of the TMMT ecosystem, showcasing the intersection of luxury brand narrative and full-stack technical engineering.

---

## 🚀 Technical Core & Performance

The platform is built on a **Component-Driven Design** philosophy, ensuring visual consistency across all service nodes.

* **Custom SPA Architecture:** Built with **Vite** and **React** for seamless state management and zero-reload transitions.
* **Engineering Precision:** Optimized for Google Lighthouse 100-scores across Performance, Accessibility, and SEO.
* **Responsive Narrative:** Fluid breakpoints engineered for high-DPI desktop displays (18:9 aspect ratios) down to mobile viewports.
* **Advanced Attribution:** Integrated frameworks for **Meta CAPI** and **GTM Server-Side** tracking logic.

## 🛠️ Service Verticals

The ecosystem acts as the digital gateway for TMMT’s specialized capabilities:

### 🌐 Web Engineering
High-performance React engines. Featured projects include:
* **Ecomsathi:** A centralized e-commerce OS for multi-channel logistics.
* **Label Muskaan Singh:** A premium fashion storefront with custom garment draping logic.
* **GrabOffer:** A lightweight deal-aggregator optimized for extreme search speed.

### ⚙️ Workflow Automation
Proprietary Python engines that eliminate manual friction:
* **Label Processor 2.0:** Automated label segregation and invoice cropping using **OpenCV** and **FastAPI**.
* **Marketplace Reconcile:** Headless **Selenium** scripts for automated financial reconciliation into Google Sheets.

### 🛒 Marketplace Infrastructure
Strategic scaling across **Amazon, Myntra, Ajio, and Flipkart**. We manage the technical nexus of inventory logic and settlement architecture.

### 🏛️ Brand Architecture
Statutory and visual entity formation:
